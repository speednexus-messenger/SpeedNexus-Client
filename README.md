# SpeedNexus-Client

Клиентская часть российского мессенджера SpeedNexus.

---

## О проекте

SpeedNexus — это российский мессенджер для быстрой, честной и безопасной связи.  
Мы не храним логи, не передаём данные третьим лицам и не навязываем слежку.  
Этот репозиторий содержит клиентскую часть приложения.

---

## Основные возможности

- [Скорость] Сообщения доставляются мгновенно
- [Приватность] Шифрование данных и защита переписки
- [Интерфейс] Минималистичный, но понятный
- [Платформы] Работает в браузере и на мобильных устройствах
- [Локализация] Сделано в России (Рязань), серверы на территории РФ
