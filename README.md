# SpeedNexus-Client
# Клиентская часть российского мессенджера SpeedNexus.

О проекте
SpeedNexus — это российский мессенджер для быстрой, честной и безопасной связи. Мы не храним логи, не передаём данные третьим лицам и не навязываем слежку. Этот репозиторий содержит клиентскую часть приложения.

Основные возможности
Наш проект позиционируется на скорости доставки сообщений, приватности и шифровании данных. Минималистичный, но понятный интерфейс. Кроссплатформенность — работает в браузере и на мобильных устройствах. Сделано в России (Рязань), серверы находятся на территории РФ.
